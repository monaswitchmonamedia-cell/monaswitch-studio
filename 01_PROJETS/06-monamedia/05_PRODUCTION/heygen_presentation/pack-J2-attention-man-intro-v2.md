## IDÉE VISUELLE V2 (cinema-director)

**Genre** : Portrait introspectif. Studio noir. Attention Man face caméra, statique 80% du temps, énergie contenue.

**Beat sheet (35s)** :
1. **0-3s** — Plan rapproché poitrine, casque légèrement incliné. Hook texte apparaît coté droit : `BRANDS LOST SOMETHING. I TOOK IT.`
2. **3-12s** — Lent push-in de 24mm vers 50mm. Attention Man ne bouge pas. Voix posée, pauses cinéma.
3. **12-22s** — Cut sec sur insert : main gantée qui se ferme lentement, particules rouges suspendues.
4. **22-30s** — Retour portrait. Très léger flux rouge derrière la visière (pouvoir 7). Sur le mot `Attention`, scan horizontal rouge passe sur la visière.
5. **30-35s** — Push final 5% sur le casque. Flux rouge bref des paumes (pouvoir 6). Logo + baseline.

**Direction technique** :
- **Focal** : 35mm pour le hook large, 50mm pour le portrait core, 85mm sur l'insert main.
- **Camera** : push-in motorisé très lent (slider électronique 1cm/s), pas de tremblement.
- **Lighting** : rembrandt classique sur le casque (key 45° gauche), rim rouge `#E10E29` à 8% derrière la nuque, fond noir pur `#000000` à 0.05 stop sous le sujet.
- **Color grading** : noirs profonds `#0A0A0A`, rouge isolé via mask sur la visière et les rims, skin (peau cou/mains) à 70% saturation, ACES filmic.
- **Lens artifacts** : aucun flare, pas de chromatic aberration, micro-grain 3%.
