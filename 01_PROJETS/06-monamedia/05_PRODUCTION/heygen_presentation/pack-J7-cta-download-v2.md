## IDÉE VISUELLE V2 (cinema-director)

**Genre** : CTA cinématique premium. Studio noir. Attention Man frontal + UI flottante "hologramme" + climax `theFIVE™` doré.

**Beat sheet (40s)** :
1. **0-3s** — Plan rapproché casque légèrement penché. Hook texte : `YOUR NEXT VIEW COULD PAY YOU BACK.`
2. **3-12s** — Push-in sur Attention Man frontal, voix. UI flottante apparaît côté droit : panneau `WATCH` qui glow rouge.
3. **12-20s** — Cuts UI : `CONFIRM` apparaît sous `WATCH`, puis `VERIFIED` apparaît sous `CONFIRM`. Chaque mot pulse rouge `#E10E29` à l'apparition puis se stabilise blanc.
4. **20-30s** — Bascule sur le climax B2B : Attention Man tourne légèrement la paume, flux rouge crée un schéma circulaire. Le schéma `theFIVE™` apparaît en doré laiton `#C9A95C` au-dessus de la paume (5 icônes en cercle).
5. **30-37s** — Attention Man face caméra direct, scan rouge subtil dans la visière. Texte CTA `DOWNLOAD THE APP. DISCOVER theFIVE™.`
6. **37-40s** — Outro logo + baseline `attention becomes value.` + tagline `We are not better. We are the only ones.`

**Direction technique** :
- **Focal** : 50mm portrait core, 35mm pour intégrer l'UI flottante côté droit, 85mm sur le climax theFIVE doré.
- **Camera** : push-in lent 50→70mm sur 30s, micro arc 5° au climax pour révéler le schéma theFIVE.
- **Lighting** : key gauche 5200K, rim rouge 8% droite, fond `#000000` pur. Au climax, ajout d'une seconde key chaude doré-laiton 3200K à 15% pour le moment `theFIVE™`.
- **VFX overlays** : panneaux UI hologramme (Remotion + glassmorphism léger), schéma circulaire 5 icônes doré laiton, scan rouge visière, flux rouge paumes (additif, pas multiplicatif).
- **Color grading** : ACES filmic, blacks crushés `#0A0A0A`, isolated red on Attention Man, isolated brass-gold sur theFIVE moment, transition très propre entre les deux palettes.
