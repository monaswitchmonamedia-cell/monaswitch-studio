## IDÉE VISUELLE V2 (cinema-director)

**Genre** : Manifesto cinéma silencieux. Pas de narrateur. La typographie + la musique + les regards portent tout.

**Beat sheet (60s)** :
1. **0-5s** — Macro plan d'iris humain en gros plan, lumière rouge balayant la pupille. Texte qui apparaît : `YOUR EYES.`
2. **5-12s** — Cuts secs : 4 visages anonymes, smartphones, contre-jour. Couleur sourde sauf un seul pixel rouge dans chaque image (la lumière de l'écran).
3. **12-25s** — Insert UI Monamedia : un compteur qui ne monte plus dans des dashboards classiques (impressions floues), puis un checkmark rouge net qui apparaît.
4. **25-40s** — Plans urbains + main qui valide sur smartphone, slow motion. Le rouge `#E10E29` est la seule couleur saturée à l'écran.
5. **40-50s** — Logo Monamedia en wipe vertical. Baseline `attention becomes value.` en frappe sèche.
6. **50-60s** — Ferme sur un œil qui se ferme + tagline `We are not better. We are the only ones.`

**Direction technique** :
- **Focal** : 50mm sur les visages, 100mm macro sur les yeux et les mains, 24mm pour les plans urbains.
- **Camera** : statique sur les portraits (locked off), micro push-in 5% sur les inserts UI, lent slider horizontal sur les plans urbains.
- **Lighting** : rembrandt court sur les visages, rim light rouge `#E10E29` à 5% d'intensité, key light en `#0A0A0A` ambiant.
- **Color grading** : monochrome désaturé (skin tones préservés à 60%), red accent isolé via mask, blacks crushés à `#050505`, whites contrôlés à `#F4F4F4`.
- **Texture** : grain 35mm subtil (5%), no glow, no chromatic aberration excessive.
