## IDÉE VISUELLE V2 (cinema-director)

**Genre** : Tutoriel cinéma. Aucun avatar visible. Voix off + plans serrés smartphone + UI app + gestes humains.

**Beat sheet (35s)** :
1. **0-3s** — Macro pouce qui appuie sur écran d'accueil iPhone. Hook texte chip : `WATCH. CONFIRM. GET SOMETHING BACK.`
2. **3-10s** — Plan smartphone de 3/4 dans une main, app Monamedia s'ouvre, UI rouge/blanc nette. Sous-titre `WATCH`.
3. **10-18s** — Insert vidéo pub qui joue dans l'app, timer 10s en haut. Visage du viewer en très flou en background.
4. **18-25s** — Pouce qui valide un check rouge `#E10E29` qui devient vert `#16A34A` (transition validation). Sous-titre `CONFIRM`.
5. **25-30s** — Insert UI : badge `VERIFIED` apparaît, pulse subtile rouge → vert. Sous-titre `VERIFIED`.
6. **30-35s** — Smartphone reposé sur table marbre clair, mains qui se retirent. Logo + baseline.

**Direction technique** :
- **Focal** : 100mm macro pour les écrans, 50mm pour les mains, 35mm pour le plan smartphone reposé.
- **Camera** : sur slider très court 5cm pour les inserts, locked off sur les UI.
- **Lighting** : softbox top sur l'écran (élimine reflets), key 45° à 4500K, contre-jour blanc froid pour faire ressortir les écrans, pas de rim rouge ici (pas Attention Man).
- **Color grading** : neutre photo-pub, blancs propres `#FAFAFA`, rouge UI Monamedia conservé à 100%, vert validation à 90%.
- **Texture** : aucun grain, look propre/produit (genre Apple keynote).
