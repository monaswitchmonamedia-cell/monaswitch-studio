## IDÉE VISUELLE V2 (cinema-director)

**Genre** : UGC documentaire premium. Vraie personne face caméra (Felix, Anna, Louis, ou volontaire). Pas d'effet, pas de pouvoir. Doc-reportage style cinéma indé.

**Beat sheet (40s)** :
1. **0-4s** — Plan rapproché épaule, sujet regarde brièvement vers la caméra. Texte écran : `WE WERE PAYING FOR GHOSTS.`
2. **4-15s** — Sujet parle face caméra dans son contexte (commerce, bureau coworking, atelier). Cuts B-roll : reports flous, dashboards abstraits, écran d'ordi avec graphiques qui montent.
3. **15-22s** — Cut sur silence : sujet baisse les yeux 2s, regard remonte. Insert texte : `Who actually watched ?`
4. **22-32s** — Sujet pose la question rhétorique. B-roll : foule en rue floue, smartphones tenus mais pas regardés, regard distrait.
5. **32-40s** — Sujet face caméra ferme : punchline `Monamedia changes the question.` puis mention `verified traffic`. Outro logo + baseline.

**Direction technique** :
- **Focal** : 35mm sur les plans larges contexte, 50mm sur le portrait parlé, 85mm sur les inserts B-roll.
- **Camera** : épaule légère (handheld stabilisé) sur les plans contexte, locked off sur le portrait parlé.
- **Lighting** : naturelle exploitée, key window light si dispo, fill blanc, pas de spot studio. Réalisme avant tout.
- **Color grading** : LUT documentaire propre type Kodak 2383 légère, blacks `#1A1A1A`, skin tones préservés à 100%, rouge Monamedia uniquement sur la fin (logo). PAS de rouge dans les plans tournés.
- **Audio** : prise son directe propre (Rode VideoMic ou cravate), réducteur de bruit léger.
