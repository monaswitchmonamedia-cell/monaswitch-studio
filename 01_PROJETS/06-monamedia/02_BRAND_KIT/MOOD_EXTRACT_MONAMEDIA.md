## IDENTITÉ AUDIO V1 — HEYGEN

> **PAS d'ElevenLabs en V1** (Felix n'a plus l'abonnement).

### Voix V1
- **HeyGen voix native EN** (à choisir parmi le catalogue HeyGen — masculine, posée)
- **HeyGen voix native FR** (à choisir parmi le catalogue HeyGen — masculine, posée)
- **Voix humaine** (Felix / Anna / Louis) pour Format B UGC
- **Sans voix** (musique + texte) pour Format D

### Critères voix
- Masculine, **confiante, posée, premium**
- **Pauses naturelles** (silence comme outil narratif)
- **Pas robotique**, pas lecture monocorde
- Ton "annonceur de bande-annonce cinéma sobre", pas comédien excité

### Protocole script (CRITIQUE)
- **Phrases courtes** : max 10-12 mots
- **Points à la ligne** systématiques (un point = une respiration)
- **Pauses `...`** placées explicitement dans le script
- **Pas de jargon**, pas de mots compliqués, pas d'anglicismes inutiles
- **Mots simples**, ancrés visuellement
- **Rythme cinématique** : montée → silence → punchline

### Musique
- **Cinématique moderne / électro / dark premium**
- Sources autorisées : YouTube Audio Library, Artlist, Epidemic Sound
- Pas de musique générique "corporate motivation"

### Silence
- **Outil narratif** : utilisé pour la **punchline** + l'**apparition Attention Man**
- 1-2 secondes de silence valent mieux qu'un mot de trop

### Mix audio
- **Voix > musique** (voix toujours dominante)
- **Effets sonores subtils** pour chaque pouvoir (whoosh, glitch, basse pulsée)
- Pas de drops EDM agressifs

- **Premium cinéma** (pas TikTok bricolé)
- **Lumière chaude domestique** pour viewers + **lumière béton/froide** pour démonstration produit
